# Text Trainer — тренажёр слепой печати

**Ссылка на веб-приложение** - [Text-Trainer](http://text-trainer.online)

**Text Trainer** — это веб-приложение для развития навыков слепой печати с адаптивной системой тренировок.  

---

## Основные возможности

- **Два режима тренировок**:
  - *Общий* — случайный текст из заготовленной коллекции для всесторонней практики.
  - *Целевой* — генерация текста, состоящего из слов, содержащих определённую букву. Тренировка строится на основе буквы, которую выбирает пользователь.
- **Мгновенная обратная связь** — подсветка правильно введённых и ошибочных символов в реальном времени.
- **Детальная статистика** — скорость (cpm), точность, количество ошибок, время тренировки.
- **История и лучший результат** — все результаты сохраняются в базе данных, для каждого пользователя отображается его рекорд.
- **Регистрация и аутентификация** — пользователи создают аккаунт и входят в систему; доступ к тренировкам защищён JWT-токенами.
- **Контейнеризация** — готов к развёртыванию через Docker Compose с использованием Nginx в качестве reverse‑proxy.

## Архитектура проекта

Проект построен по классической трёхуровневой архитектуре с чётким разделением ответственности:

- **Controller layer** — REST-контроллеры обрабатывают HTTP-запросы, валидируют входные данные и возвращают ответы.
- **Service layer** — бизнес-логика: генерация текстов, регистрация пользователей, сохранение результатов.
- **Repository layer** — JPA-репозитории для работы с PostgreSQL.

**Безопасность** реализована с помощью **Spring Security** + **JWT**:
- Пароли хранятся в захешированном виде (BCrypt).
- Токен выдаётся после успешного логина и передаётся в заголовке `Authorization: Bearer <token>` при каждом запросе к защищённым эндпоинтам.
- Фильтр `JwtRequestFilter` проверяет валидность токена и устанавливает контекст аутентификации.

**Клиент-серверное взаимодействие** — REST API с JSON-форматом данных. Клиентская часть (статический HTML/CSS/JS) может раздаваться либо через Spring Boot (встроенный Tomcat), либо через Nginx в продакшн-среде.

## Запуск проекта

1. Убедитесь, что установлены **Docker** и **Docker Compose**.
2. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/ваш-username/texttrainer.git
   cd Text-Trainer
   ```
3. Создайте файл `.env` на основе следующего примера и заполните все поля:
   ```
   DB_PASSWORD=ваш_пароль_для_БД
   JWT_SECRET=JWT_ключ_не_менее_32_символов
   ```

3. Отредактируйте файл `src/main/resources/application.properties` по следующим параметрам:
   ```
   spring.datasource.username=<Имя_пользователя_в_БД>
   spring.datasource.password=<Пароль_от_БД>
   ```
4. Запустите контейнеры:
   ```bash
   docker-compose up -d
   ```
5. Откройте браузер и перейдите по адресу `http://localhost:80` (или ваш IP-адрес сервера).
